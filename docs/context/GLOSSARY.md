# Glossary

| Term | Meaning |
|---|---|
| Observation | Raw or processed sensor report; not a WorldState fact. |
| WorldState | Deterministic state derived from ordered events. |
| TaskGraph | Typed high-level steps; never joint commands. |
| SemanticAction | A validated action request such as `grasp` or `place`. |
| ActionResult | Execution outcome from Motion / Robot Runtime. |
| VerificationResult | World Model decision backed by evidence. |
| Scenario Manifest | Versioned scene, seed, task and fault configuration. |
| Oracle | Simulator ground truth; excluded from sensor metrics. |
